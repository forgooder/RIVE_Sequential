- GraIL: WN-v3 无最终 Sequential source adapter；FB-v3/v4 缺与 adapter 可核验配对的正式 A0 checkpoint。
- NBFNet: WN-v3、WN-v4、FB-v2 缺同协议可核验的 base+adapter 配对资产。

- ULTRA-4G: WN-v3 缺正式配对资产；其余七格按冻结协议执行。
- CBLiP、Context Pooling、MoKGR：8/8 均完成独立 test scorer、source scale 回放和 checkpoint provenance 门禁。
- DuetGraph：7/8 完成；FB-v4 所需原始 base checkpoint SHA256 为 `930b143e...`，本地仅有不匹配的 `816e6633...`，按要求不重训、不替换，状态为 `CHECKPOINT_PROVENANCE_BLOCKED`。
